# Music Flow 安装包

这里只放 Windows 安装包和版本清单，**没有源码、没有 API 密钥**。

- 源码在私有仓库，不公开。
- 密钥在每个人自己电脑的凭据管理器里，不会进安装包。
- 应用里「检查更新」读的是本仓库的 [`latest.json`](https://raw.githubusercontent.com/terminaterfxy/music-flow-releases/main/latest.json)。
- 安装包在 [Releases](https://github.com/terminaterfxy/music-flow-releases/releases)。发给同事用 `.exe`。
